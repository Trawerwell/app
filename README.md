# AppPicker

Приложение для Windows 10/11: показывает открытые программы, позволяет искать их и добавлять в собственный список. Выбранные программы подсвечиваются пурпурным. В списке отображаются иконки, если Windows разрешает получить путь к исполняемому файлу.

## Запуск

Скачайте `AppPicker.exe` из последнего [релиза](https://github.com/Trawerwell/app/releases/latest) и откройте его. Публикуемый файл рассчитан на Windows x64 и содержит .NET, поэтому отдельная установка .NET не требуется.

AppPicker обновляет список открытых приложений каждые три секунды. Выбор сохраняется в `%LOCALAPPDATA%\AppPicker\settings.json` и восстанавливается при следующем запуске. Если выбранная программа закрыта, она остаётся в списке с пометкой «Не запущено». Список служит для организации выбора; на работу и видимость других приложений он не влияет.

## Сборка из исходников

Установите .NET 8 SDK. Затем выполните в папке проекта:

```powershell
dotnet publish .\AppPicker.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\publish
```

Готовый файл: `publish\AppPicker.exe`.

## Приватность экрана

Переключатель «Исключить окно AppPicker из захвата экрана» вызывает официальный Windows API `SetWindowDisplayAffinity` с `WDA_EXCLUDEFROMCAPTURE` **только для окна AppPicker**. Функция доступна начиная с Windows 10 версии 2004. Результат зависит от версии Windows и способа захвата; полной защиты от записи она не гарантирует.

AppPicker не скрывает окна сторонних программ. Для трансляции одной программы без рабочего стола выберите в программе для трансляции режим показа отдельного окна.

## Исходники

C#, .NET 8, WPF; Win32 API используется для перечисления окон и настройки захвата собственного окна.
